2.0 — GENERATION PRINCIPLES
--------------------------------------------------------------------------------

  P1  SILHOUETTE FIRST (LAW 1). The biro illusion lives in the outline:
      variety of height, lean, girth, crown shape. Every parameter
      below exists to move the silhouette.
  P2  ARCHETYPES ARE REGIONS, NOT TEMPLATES. Titan / slender / gnarled
      are neighborhoods in one continuous parameter space. ~20% of
      draws intentionally land BETWEEN regions — a forest of pure
      archetypes is a forest of clones with extra steps.
  P3  DETERMINISM (LAW 6). Every draw comes from mulberry32 in a FIXED
      ORDER. The param table is versioned; changing it is a breaking
      change (seeds regenerate differently — journal the version).
  P4  BUDGET HONESTY. Each generator emits its geometry-call cost so
      the embedder can dial archetype mixes per zone budget.
  P5  COLLIDER HONESTY (LAW 3). Organic visuals ride on clean AABB
      sets. The visual wobbles; the physics does not.

2.1 — THE PARAMETRIC TREE: generateParametricTree(seed, opts)
--------------------------------------------------------------------------------

  INPUT:  seed (uint32), opts = { scale, girth, height, lean,
          branchiness, foliageVolume } — any may be left null, in
          which case the archetype draw supplies it.

  PHASE A — BODY PLAN (the archetype draw)
  ------------------------------------------------------------------
    ARCHETYPE    height    trunkR    lean      taper k   branches
    -----------  --------  --------  --------  --------  ----------
    TITAN        25-35m    2.5-3.5m  0-4 deg    0.35      3-6 (heavy)
    SLENDER       8-12m    0.25-0.4 15-25 deg   0.85      2-4 (light)
    STOUT/GNARLED 5-7m    0.8-1.4m  5-15 deg   0.60      2-4 limbs
    BLEND ZONE    interpolate any two rows (20% of draws)

    Draw order (FIXED, determinism): height -> trunkR -> lean ->
    taper -> branchiness -> foliageVolume -> leanAzimuth -> noise
    offsets. One rng, one order, forever.

  PHASE B — TRUNK: SEGMENTED TAPER WITH ACCUMULATED LEAN
  ------------------------------------------------------------------
    N segments (titan 6-8, slender 4-5, gnarled 3-4). Along t in
    [0,1] (base to top):

      radius:     r(t) = trunkR * (1 - t)^taper          ...taper k
      lean curve: total lean L degrees, distributed with an ease
                  profile so curvature reads naturally:
                    s(t) = 3t^2 - 2t^3        (smoothstep)
                  cumulative lean at t:  L * s(t) + C * noise1D(t)
                  where C = L * 0.4 (curvature character) and

                  noise1D(t) = deterministic value noise:
                    i = floor(t), f = t - i
                    a = hash01(seed, i), b = hash01(seed, i+1)
                    u = f*f*(3-2f)
                    return a + (b - a) * u          (in [-1,1] after
                                                       remap)

    CONSTRUCTION, TWO WAYS (both legitimate):
      B1  STEPPED DRIFT (works TODAY, no primitive changes): each
          segment is a VERTICAL cyl at an offset position —
          P(i+1) = P(i) + (dx_i, segLen, dz_i) where the horizontal
          drift per segment follows the lean curve. The stack of
          slightly-offset segments looks hand-assembled — because a
          doodled tree IS hand-assembled. Colliders: one AABB per
          segment. Recommended default.
      B2  TRUE TILT (after the recipe 'tilt' field lands in the
          builder): segments rotated to the local tangent; collider =
          the AABB of the tilted segment. Smoother; use for slender
          trees where lean is the identity.

  PHASE C — BRANCHING: THE DA VINCI BUDGET
  ------------------------------------------------------------------
    Branch slots at t_b sampled in [0.4, 0.8] (count from
    branchiness). For each slot, in t-ascending order:

      azimuth:      phi_b = rng * 360 deg (seeded)
      angle:        theta_b = 25-45 deg off the trunk axis
      child length: L_b = remainingTrunkLength * (0.60-0.75)
      child girth:  g_b = g_parent * sqrt(1 / nSiblings)
                    (da Vinci's area-preservation rule — the visual
                    justification: branches that thin by area, not by
                    whim, read as REAL to the eye)

    Recursion depth budget: 2 levels (titan branches are platforms;
    slender branches are perches). GNARLED SIGNATURE: instead of
    tapering to a tip, the top splits into 2-4 equal limbs (the
    multi-limb split IS the archetype) at t = 0.55-0.7.

  PHASE D — FOLIAGE: CROWNS AND PADS
  ------------------------------------------------------------------
    Crown = K clusters (K from foliageVolume, 3-9) of sphere()
    calls, ink GR, noCollide (foliage is ink, LAW 4) — EXCEPT:
      leaf pads: optional thin slab colliders (0.3m thick) placed
      under 1-2 crown clusters where the design wants a standable
      canopy route (titan decks use these as fringe platforms).
    SLENDER SIGNATURE: crown centroid offset along the lean
    direction by (0.2-0.35) * crownRadius — the tree grows toward
    its light. This one parameter does more for "not a clone" than
    any other in the file.

  PHASE E — TACTICAL FURNITURE (the game layer; obeys LAW 8)
  ------------------------------------------------------------------
    TITAN (the colossal tree — full spec):
      - Buttress root ramps: 3-5 wedges climbing the base in a
        spiral. Spiral math: angle theta(t) = theta0 + t * 2pi * R,
        height y(t) = t * H_climb. With run 0.5m/step at radius
        (trunkR + 0.5): steps per revolution =
          floor( 2pi * (trunkR + 0.5) / 0.5 )  ~=  44 at trunkR 3.0
        rise per revolution = 44 * 0.28 ~= 12.3m. One revolution
        therefore climbs from ground to the mid-deck; landings every
        4.0m of rise (LAW 8) become wide shelves (2m x 1.6m).
      - Hollow trunk niche: bore rInner = 1.5 (derivation in 2.2:
        clear = 2*rB - floorFill >= 2.2), height 4-6m, entered via
        arch() openings (BP4) — a CQB room inside the tree.
      - Canopy combat deck at Y = 20-24: slab 12-16m across,
        parapets 0.9-1.1m (BP3), grapple rings +6-10m overhead.
      - Root skirt: 4-7 facetedRocks (BP4) at the base ring,
        heights clamped 0.8-1.3m — waist cover that grew there.
    SLENDER: crown perch (1 leaf pad), no interior.
    GNARLED: limb platforms (pads on the split), root cover skirt.

  PHASE F — EMISSION
  ------------------------------------------------------------------
    Output = { parts[], colliders[], anchors{}, cost{} } where
    anchors include grapple seats (branch tip + 1.5m clearance),
    deck edges, and the interior anchor. Cost: titan 70-110 calls,
    gnarled 30-40, slender 22-30, blends in between — the embedder's
    archetype-mix dial consumes these numbers directly.

2.2 — THE CURVED HOLLOW LOG / SPRINT TUNNEL
--------------------------------------------------------------------------------

  CROSS-SECTION MATH (the governing derivation):
    Let bore radius rB, floor fill depth f (raised flat floor inside
    the bottom of the tube). Clear vertical headroom inside:
        clear = 2 * rB - f
    LAW 8 requires clear >= 2.2 with f = 0.5 (a walkable flat floor
    instead of a curved one — players slide on flats, not on troughs):
        rB >= (2.2 + 0.5) / 2 = 1.35    ->  use rB = 1.4-1.5
    Wall thickness w = 0.35-0.5 -> outer radius rO = rB + w ~ 1.8-2.0.
    Bore width at floor level: 2*sqrt(rB^2 - (rB - f)^2) ~ 2.2m —
    the 1.8m clearance invariant holds with margin for jitter.

  CENTERLINE MATH — KINKED, NOT SMOOTHED (LAW 1):
    A doodled log is not a bezier; it is 2-4 STRAIGHT SEGMENTS with
    confident kinks. Spec: a seeded polyline of axis-aligned
    segments, lengths 6-14m, kink angles 20-40 deg (azimuth turns),
    vertical profile optionally descending 0-2m end to end (drainage
    character). Each segment is axis-aligned — which keeps every
    collider a clean AABB (P5) and every bore constructible with
    today's primitives.

  PER-SEGMENT CONSTRUCTION (stave method — works TODAY):
    A straight bore along axis 'x' or 'z' is 6 axis-aligned boxes:
      floor slab    (walkable, nav)      top at y_c - rB + f
      ceiling slab  (blocker)            bottom at y_c + rB - 0.3
      2 side walls   (blockers)          at +- (rB + w/2)
      2 optional corner fills (visual, noCollide) softening the
      square-ness of the interior corners
    plus bark detailing on the exterior (bands, moss tufts — all
    < 0.3m, noCollide, LAW 4). After BP4 lands, each segment
    collapses to ONE hollowCyl() call plus the floor (04, 4.1) —
    same numbers, fewer calls, rounder bore.

  EXTERIOR CLIMB — THE SHELF-FUNGUS SPIRAL:
    Shelves spiral the outer wall: shelf i at
      angle:   theta_i = theta_0 + i * (30-45 deg)
      height:  y_i = y_base + i * 0.28          (rise, LAW 8)
      run:     arc spacing rO * dTheta ~= 1.0-1.4m (>= 0.45 holds)
      seat:    box 1.2 x 0.12 x 0.8 protruding (rO + 0.4) from axis
    Landings: every ceil(4.0 / 0.28) = 15 shelves, a wide landing
    (2m x 1.6m). The spiral tops out at the catwalk.

  TOP CATWALK:
    Slab along the top chord (width ~ 1.1 * rO), parapets 0.9-1.1m
    both sides (BP3 contract), grapple rings +6-10m overhead spaced
    8-12m, chain continuity <= 18m (inspector rule).

  TACTICAL ROLES: interior = CQB corridor (1.8/2.2 proven above);
  catwalk = high-ground lane with exposed flanks (deliberate);
  junction of two kinked segments = natural hold point.

2.3 — ALGORITHMIC BIRO SKETCH JITTER (the hand-drawn layer)
--------------------------------------------------------------------------------

  The shader crosshatches whatever normals it receives. Jitter's job
  is to make sure it never receives a boring one. Three layers, all
  deterministic, all applied AT GENERATION (the shader is untouched):

  J1 — VERTEX DISPLACEMENT (opts.jitter = { amp, seed } on any prim)
    Every unique vertex p is displaced:  p' = p + amp * v
    where v is a unit vector from hash01(seed, positionHash(p)).
    CRITICAL IMPLEMENTATION RULE: key the noise by POSITION HASH, not
    vertex index — vertices shared between faces MUST displace
    identically or the merged mesh cracks along seams.
    amp: micro 0.04-0.06m (masonry, furniture), meso 0.08-0.12m
    (bark, rock, terrain skin). Zero extra geometry calls — a
    post-construction pass inside the primitive, before merge.

  J2 — FACET VARIANCE (cyl / cone / sphere family)
    Per radial segment i:  r_i = r * (1 + eps * hash01(seed, i)),
    eps = 0.05 (subtle) to 0.12 (gnarled). Plus per-ring vertical
    wobble +-0.05m. THIS is why low segment counts (8-12) are a
    feature: the facets are wide enough for the variance to read.
    A jittered 10-seg cylinder is a hand-rolled tube; a smooth
    32-seg cylinder is a pipe. Doodles have facets.

  J3 — ROTATION SNAP AVOIDANCE (placement level)
    Seeded 3-7 deg Y-rotations on every placed prop — nothing in a
    notebook is perfectly axis-aligned. Colliders: snap to the
    UNROTATED box (or the rotated AABB + 0.1m margin). Visual
    organic, physical honest (P5). The mismatch is under the jitter
    noise floor and nobody's slide ever snags on it.

  THE SEPARATION PRINCIPLE (what jitters vs what never does):
    JITTERS: silhouette vertices, facet radii, prop rotations,
             crown offsets, bark detail placement
    NEVER:   collider alignment, tactical heights (0.8-1.3 / 2.5-3.0),
             clearances (1.8), headroom (2.2), stair rise/run,
             ring clearances (1.5), floor surfaces players stand on
    The rule of thumb: if a PLAYER'S FEET or a BULLET touches it,
    it's honest geometry; everything else may wobble.

2.4 — ACCEPTANCE TESTS
--------------------------------------------------------------------------------

  T1  CLONE DEATH: 100 seeded trees of one archetype produce >= 60
      distinct silhouette hashes (bounding-ratio + vertex-histogram
      composite); zero identical neighbors within 18m (diversity
      guard, vignette level).
  T2  DETERMINISM: seed + param version -> byte-identical parts,
      20 regenerations.
  T3  INVARIANTS: every generated tree's tactical furniture passes
      LAW 8 checks (rise/run, landings, cover clamps, ring
      clearances) BEFORE emission — measured, not assumed.
  T4  BORE MATH: every hollow-log segment's measured interior
      >= 1.8m wide and >= 2.2m clear (sandbox-measured on 50 seeds).
  T5  JITTER SAFETY: 1,000 jittered prims produce zero NaN
      vertices, zero cracked seams (position-hash rule), and zero
      collider violations (colliders computed from jittered bounds).
  T6  BUDGET HONESTY: emitted cost metadata matches actual geometry
      call counts within +-1 on all archetypes.
