3.0 — THE DOCTRINE: SCALE BY FUNCTION, NOT BY CONSISTENCY
--------------------------------------------------------------------------------

The Giant Classroom works because its objects are scaled to their
TACTICAL FUNCTION, not to a uniform diorama ratio. A pencil can be a
0.3m desk prop in one map and a 30m hero ramp in another — both are
correct because ROLE decides size. The Colossal Transform is a table,
not a vibe:

  TACTICAL ROLE          GOVERNING DIMENSION            CANONICAL EXAMPLES
  ---------------------  -----------------------------  -------------------
  waist_cover            height clamps to 0.8-1.3m      eraser, inkwell,
                                                          coconut, mug
  full_cover             height clamps to 2.5-3.0m      book stack, conch,
                                                          monitor, crate
  interior_corridor      bore >= 1.8m wide,             pencil tunnel,
                        >= 2.2m headroom               hollow log, pipe
  catwalk_surface        top deck + parapet 0.9-1.1m   ruler, driftwood,
                                                          book top, branch
  ramp / staircase       rise <= 0.30, run >= 0.45,    book ramp (pages
                        landings per 3.4               as steps)
  landmark_anchor        15-40m tall; anchors 2+        pencil tower, titan
                        sightlines                     tree, lighthouse
  grapple_anchor         ring seat w/ 1.5m clearance   lamp arm, mast,
                                                          branch tips
  hazard                 lethal drop / damage zone     inkwell abyss,
                                                          sharpener ridge

  k = doodleMeters / realMeters is computed PER ROLE from the target
  dimension — never inherited from a global scale. The concept doc's
  Section 2 (Notebook Premise) DECLARES the metaphors; this table
  prices them. A map may contain a mug at waist_cover scale beside a
  mug at landmark scale only if the concept says so and the fairness
  gates (3.3) agree.

3.1 — THE COLOSSAL CONTRACT (every set piece signs it)
--------------------------------------------------------------------------------

  A colossal_setpiece AST node is not valid until all seven clauses
  hold. These are VALIDATION GATES (R5 engine), not aspirations:

  C1  GROUNDED BASE. The footprint touches Y=0 within tolerance;
      no floating heroes (the blacklist's oldest rule).

  C2  ENTRY. At least one legitimate route up: stairs/ramp honoring
      rise/run, PLUS optionally a grapple route. "Legitimate" means
      the A* solver paths it — not that it looks climbable.

  C3  INTERIOR INVARIANTS (if traversable inside): 1.8m clearance,
      2.2m continuous headroom, landing every 4.0m of climb:
        landings = ceil(rise / 4.0) - 1, each 1.5m deep, flat.

  C4  SUMMIT CATWALK. If there is a top surface, it is a combat deck:
      parapets 0.9-1.1m (cover that reads), ring overhead +6 to
      +10m, and at least one fire position per exposed axis.

  C5  SKILL FACE. At least one surface for each declared movement
      verb the map supports:
        wall-kick chimney: parallel faces 2.4-3.2m apart,
          climbable height <= 3 faces of kick arcs
        double-jump route: hops <= 2.5m each (the A* jump sim's max),
          with standing room between hops
        slide gap: 3.5m max (the slide sim's number)
      The movement kit is a level design vocabulary; colossal pieces
      are its nouns.

  C6  EXITS >= 2 (G2, applied to set pieces): no camping coffins.
      A summit with one stair is a god spot; the exploit detector
      already knows this — now it's a generation-time clause.

  C7  HAZARD HONESTY. Lethal falls wear INK.RED edges; railings
      (or DECLARED drop-plays, BP3 of the rebuild set) bound every
      deck edge where fall > 3.0m. The player must always be able
      to see the rules of the surface they stand on.

3.2 — WORKED ANATOMY: THE COLOSSAL PENCIL (gold-standard calibration)
--------------------------------------------------------------------------------

  The Classroom's pencil, reverse-engineered into contract clauses —
  the calibration fixture for the whole system:

    ROLE: landmark_anchor + ramp + catwalk  |  k: 30m / 0.18m real
    BODY:   hexagonal prism, 6 boxes (faceted on purpose — LAW 1's
            sketchiness), length 30m, lying at a 4-6 deg incline so
            the far end forms a natural ramp rise (~2.8m over length)
    TIP:    cone(),BK — the "graphite" writes the hazard clause: the
            last 2m are a RED-edged slide-off (C7)
    ERASER: cyl cap at full_cover scale (2.8m) — the anchor bunker
    SPINE:  stepped wedges along one upper facet: rise 0.28 / run
            0.5, one landing mid-length (C2, C3 pricing)
    CATWALK: the upper facet itself, parapet boxes every 3m (C4)
    SKILL FACE: the eraser-side face pair = wall-kick chimney
            2.8m wide (C5); double-jump bounces via two facet ribs
    EXITS:  spine base + eraser hatch + tip slide (C6)
    RINGS:  three along the length at +7m (3.3's chain rules)

  If the generator can produce THIS from a recipe + contract, it can
  produce the beach's conch bunker and the forest's titan by the
  same mathematics.

3.3 — GRAPPLE HIGHWAY TOPOLOGY (rings as infrastructure)
--------------------------------------------------------------------------------

  THE MODEL: rings are nodes; an edge exists when ring B is
  reachable from ring A's swing envelope (spacing < 18m, per the
  inspector's continuity rule). A map's highway is this graph; its
  CONNECTED COMPONENTS are the traversal promises the map makes.

  PLACEMENT RULES (relative to colossal set pieces):
    R1  OVERHEAD: ring_y = deck_y + 6..10 (launch height for
        momentum conversion — the game's core verb).
    R2  WALL CLEARANCE >= 1.5m from ANY collider, measured along the
        FULL swing arc, not just at rest.
    R3  SWING ARC VALIDATION (the pendulum sweep): for a cable
        length L_c (ring to entry point), sample the arc every 15
        deg; at each sample, test a swept capsule (r = 0.6m) against
        the loose octree. Any obstruction -> reseat the ring
        +-1.5m (max 3 retries) -> journal if unresolvable. This is
        the rule that keeps players from clipping through the
        branches the titan generation just hung everywhere.
    R4  CHAIN MOMENTUM PROFILE: consecutive rings sit 0-3m LOWER
        (descending chains preserve speed — uphill chains kill the
        verb). Exception: LAUNCHER rings at a chain's start may sit
        +2m. Max chain length before a forced landing pad: 5 rings
        (fatigue and fairness).
    R5  COLOSSAL INTEGRATION PATTERNS:
          titan tree   = VERTICAL highway (base ring, mid-crown
                         ring, canopy deck ring)
          fallen log   = HORIZONTAL chain along the catwalk
          ravine strat = CROSS-GAP chains (both rims + arc sweep
                         against the cliff faces)
          cathedral_   = LONG-AXIS chains down the nave (the
          cross          grand swing line)
    R6  CONSTELLATION BUDGETS (per strategy, enforced by the R5
        validator): arena_ring 20-30 | warren 16-24 | cathedral_cross
        24-34 | terraced 26-36 | ravine 30-45.

  MULTIPLAYER FAIRNESS (request.md reality R3): ring-graph access is
  measured PER TEAM SPAWN — symmetric highway access within +-15%
  travel time, a validation gate in the same family as spawn
  exposure symmetry. A grapple highway only one team can board is a
  god spot at commute scale.

3.4 — THE COLOSSAL AST NODE (how it enters the pipeline)
--------------------------------------------------------------------------------

JSON

  {
    "id": "setpiece_pencil_hero",
    "type": "colossal_setpiece",
    "recipeRef": "pencil_hero",          // dream-recipe/1.0 (BP1)
    "transform": { "x": -14, "y": 0, "z": 8, "rotY": 21 },
    "scaleRoles": ["landmark_anchor", "ramp", "catwalk"],
    "contract": {
      "entry": ["spine_stairs", "eraser_hatch"],
      "interior": null,
      "summit": { "deck": "upper_facet", "parapet": true,
                  "rings": ["ring_p1", "ring_p2", "ring_p3"] },
      "skillFaces": ["eraser_chimney"],
      "exits": 3,
      "hazards": ["tip_slide RED"]
    },
    "cost": { "geometryCalls": 64, "colliders": 71 }
  }

  PIPELINE SEAT: the embedder places set pieces as HERO ANCHORS
  (zone-level, from strategy priors + concept Section 8's Tier-4
  list); the Surface Grid ingests their decks as TIER SURFACES (a
  titan canopy is just tier 3 with better hair); the Vignette
  Composer anchors on their surfaces (a checkpoint ON the pencil
  spine); the A* validator runs clauses C1-C7 as gates; the ring
  graph consumes their ring seats.

3.5 — ACCEPTANCE TESTS
--------------------------------------------------------------------------------

  T1  CONTRACT GATES: 100 seeded set pieces pass C1-C7 or are
      rejected with the failed clause named (a rejected hero falls
      back to a cousin recipe, never a hole in the map).
  T2  CALIBRATION: the generated Colossal Pencil's measured metrics
      (colliders, tiers, rings, exits) land within +-15% of the
      hand-authored Classroom pencil's — the gold standard prices
      the generator.
  T3  SWEEP HONESTY: fault-injected obstructions inside swing arcs
      are caught by R3 (rings reseat or journal; zero clipped
      swings in 200 simulated chains).
  T4  MOMENTUM PROFILE: generated chains are descending-or-launcher
      (R4) — zero uphill chains; every 5-ring chain ends on a
      landing pad.
  T5  FAIRNESS: per-team highway access within +-15% across 50
      seeded multiplayer layouts.
  T6  SILHOUETTE: two seeds of the same recipe produce distinct
      bounding-ratio signatures (jitter + param spread did their
      job).
