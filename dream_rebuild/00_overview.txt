WHAT THIS DOCUMENT SET IS
--------------------------------------------------------------------------------

A production-ready Architectural Upgrade Blueprint answering the audit's
five vectors (A-E) and its meta-prompt mission. It is written against the
REAL Dream: 4,709 lines of core pipeline, 29 prefabs, 21 macro templates,
a fixed scaffold, regex concept parsing, and a semi-random quality score.
Every system in this set is specified to be implementable in that codebase,
with those primitives, by deterministic JavaScript — no runtime LLM, no
new rendering pipeline, no rewrites of what already works.

THE PRIME DIRECTIVE OF THE REBUILD
--------------------------------------------------------------------------------

  DETERMINISTIC FIRST. Every system must work fully offline, zero-LLM,
  reproducible from a seed. Where the audit's Vector E (LLM orchestration)
  applies, the LLM is a PLANNER that reads and writes the intermediate
  representation — it never emits geometry code, and the pipeline never
  depends on it being present. If the LLM is unavailable, a deterministic
  Stand-in Director (rule-based) produces the same artifacts, just less
  imaginatively. This preserves Dream's single most valuable property
  (the audit says it explicitly): fully offline, deterministic, testable.

THE SEVEN ROOT CAUSES -> THE REBUILD'S ANSWERS
--------------------------------------------------------------------------------

  RC1  Fixed scaffold template (THE BIGGEST)  ->  FILE 01: Zone Graph
       Layout Engine. The scaffold's one fixed answer becomes five
       layout STRATEGIES driven by concept + seed.
  RC2  No spatial composition intelligence    ->  FILES 01+02: zones,
       rooms, corridors, doorways as first-class semantic nodes in a
       Scene Tree; asymmetry and multi-tier by construction.
  RC3  Template poverty (3/theme, 1 prop)     ->  FILE 04: Vignette
       Composer — combinatorial micro-scenes assembled from the existing
       29 prefabs instead of hand-authored templates.
  RC4  Concepts decorative, not structural    ->  FILE 01 Stage 1: the
       Concept Interpreter finally READS sections 4-8 and compiles them
       into a Zone Program. The wish document gets a fulfillment engine.
  RC5  Debate engine is a stub                ->  FILE 06: LLM orchestra-
       tion as an optional AST-planning layer with a deterministic
       stand-in; the debate protocol survives, the mock dies.
  RC6  Simulation is meaningless              ->  FILE 05: real grid A*
       reachability, raycast sightlines, cover-interval analysis; scores
       that can actually FAIL.
  RC7  No multi-pass refinement               ->  FILE 05's Repair Agenda:
       measured deficiencies drive targeted re-composition passes until
       the map passes or exhausts its budget.
