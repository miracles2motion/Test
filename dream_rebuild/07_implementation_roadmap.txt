7.0 — GROUND RULES OF THE ROADMAP
--------------------------------------------------------------------------------

  G1  THE RENDERER IS NEVER TOUCHED. The rebuild lives entirely in
      generation (Node.js CLI side) and emits the same primitive API
      the renderer already consumes. Zero risk to the game runtime.
  G2  EVERY PHASE IS FLAG-GATED. `--layout v2`, `--dress v2`, etc.
      Rollback is a flag flip; the legacy path survives one full
      release after each promotion.
  G3  EVERY PHASE SHIPS WITH ITS ACCEPTANCE GATES WIRED INTO CI.
      A phase is not done when the code exists; it is done when the
      gates close.
  G4  DETERMINISM LANDS FIRST. Nothing downstream is testable until
      seeded reproducibility exists, so it is Phase R0, not a virtue
      for later.
  G5  EFFORT SIZING: S (< 1 dev-week), M (1-2 weeks), L (2-4 weeks)
      for one strong JavaScript engineer. Sequencing matters more than
      the estimates.

PHASE R1 — THE SCENE TREE & COMPILER (M-L) — "the AST, de-risked first"
--------------------------------------------------------------------------------
  STRATEGY: build the compiler BEFORE the layout engine, and prove it
  by PARITY: hand-transcribe the current fixed scaffold layout into a
  tree (scaffold.tree.json), compile it, and require the output to
  match today's scaffold output structurally (same primitives, same
  counts, same clearances — byte-identity is not required, structural
  equivalence is). The AST is thereby validated against a known-good
  build before anything depends on it.
  DELIVERABLES
    - Tree schema v1.0 + validators L1/L2 (File 02)
    - scene-compiler.js with node-type emitters, hand/dream file
      regions, import dedup, node-id audit trails, cost metadata
    - map-inspector reborn: reads the tree; regex scraping retired
    - geometry-validator wired as the final gate (unchanged module)
  GATES: File 02 T1-T5; parity build accepted; compile 5x in place
      with zero duplication.

7.9 — THE GRADUATION TEST (the benchmark from File 00, restated)
--------------------------------------------------------------------------------

  A rebuilt Dream map, chosen at random from 20 seeded runs, must:
    - compile to >= 300 colliders, >= 180 geometry calls, 20-45 rings
    - populate >= 3 tiers, >= 4 interior rooms with doorways
    - prove zero unreachable pickups/spawns/sniper posts (R-gates)
    - score >= 75 on the real validator, unrepaired or repaired
    - and pass the BLIND TEST: side by side with the Giant Classroom,
      a player who has never seen either cannot reliably say which
      one the machine made.

  "Dream is done dreaming when its maps are indistinguishable from
   its teacher's."
