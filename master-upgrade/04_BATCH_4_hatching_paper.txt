Time: ~2–3 hours. Now the shading reads as PEN LINES and the screen
reads as PAPER. This is what separates "toon game" from "ballpoint."

Two things here:

      flat gray.
  (B) PAPER GRAIN — a faint paper texture over the whole frame.

=====================================================================
PART A — HATCH SHADING
=====================================================================
The cheapest, most robust trick: put a hatch pattern into the toon
material's shadow region. Since MeshToonMaterial only does 2–3 bands,
we can either (1) map a hatch texture onto the whole object so the
hatch only becomes visible in shadow, or (2) use a custom toon shader.
We'll do (1) first (easy), then show (2) if you want more control.

A1 — EASY: HATCH IN THE SHADOW VIA gradientMap + MAP
  - Keep your 3-step gradientMap from Batch 2 (light/mid/shadow).
  - Add a repeating hatch line texture as the material's map, and let
    the toon shading multiply it. The lines read most in the shadow
    band, which is exactly what crosshatching is.

  Build the hatch texture with a tiny canvas (no image file needed):

    function makeHatchTexture(angleDeg = 45, spacing = 6) {
      const c = document.createElement('canvas');
      c.width = c.height = 64;
      const g = c.getContext('2d');
      g.strokeStyle = '#000000';
      g.lineWidth = 1;
      // draw parallel diagonal lines
      g.save();
      g.translate(32, 32);
      g.rotate(angleDeg * Math.PI / 180);
      for (let i = -64; i < 64; i += spacing) {
        g.beginPath();
        g.moveTo(i, -64);
        g.lineTo(i, 64);
        g.stroke();
      }
      g.restore();
      const tex = new THREE.CanvasTexture(c);
      tex.wrapS = tex.wrapT = THREE.RepeatWrapping;
      return tex;
    }
    const hatch = makeHatchTexture(45, 6);

  Attach to the ink material:
    const m = new THREE.MeshToonMaterial({
      color: hex,
      gradientMap,
      map: hatch,
      alphaMap: ... // (optional) to keep lines only in shadows
    });

  PROBLEM: with just `map`, the hatch shows in LIGHT areas too (faint
  white-on-white lines). That can look great (contour hatch) or messy.
  Tune `hatch.repeat` and whether you set it as `map` vs `alphaMap`.

A2 — BETTER: PUT HATCH ONLY IN SHADOW (custom toon shader)
  If you want TRUE ballpoint behavior — clean in light, hatch in
  shadow — write a small ShaderMaterial based on the classic toon
  shader and sample the hatch ONLY in the dark band. Sketch:

    // fragment main idea (GLSL):
    //   float l = dot(normal, lightDir);          // 0..1 lambert
    //   float band = step(0.3, l);                 // 0 = shadow band
    //   vec3 hatch = texture2D(hatchMap, vUv * hatchScale).rgb;
    //   vec3 color = base;
    //   color *= mix(vec3(0.35), vec3(1.0), band); // shadow darkens
    //   color *= mix(hatch, vec3(1.0), band);      // hatch only in shadow
    //   gl_FragColor = vec4(color, 1.0);

  This is ~15 lines of GLSL. It is the difference between "looks like
  a toon game" and "looks hand-hatched." Worth the hour.

  NOTE: if you go custom-shader, you must handle your outline (Batch 3)
  separately, since OutlinePass works on materials it can render — it
  still works, but test it.

---------------------------------------------------------------------
PART B — PAPER GRAIN OVERLAY
---------------------------------------------------------------------
A faint noise over the whole frame sells "paper" instantly and hides
banding artifacts from the toon shading. Two ways:

B1 — EASY: add a full-screen grain via a shader pass in the composer
  (needs a custom ShaderPass in your Batch 3 composer). ~20 lines.

B2 — EASIEST (no code): pre-multiply a subtle grain into your paper
  background and fog by using a very low-alpha noise texture as the
  scene background via a large plane behind everything. But honestly,
  the per-pixel overlay looks better.

If you use the composer from Batch 3, add this as the LAST pass:

  // grain.frag (GLSL):
  //   uniform sampler2D tDiffuse; uniform float amount;
  //   float n = fract(sin(dot(vUv, vec2(12.9898,78.233))) * 43758.5453);
  //   vec3 col = texture2D(tDiffuse, vUv).rgb;
  //   col += (n - 0.5) * amount;      // amount ~ 0.02
  //   gl_FragColor = vec4(col, 1.0);

Keep the grain SUBTLE (amount 0.01–0.03). Too much looks like a dirty
screen, not paper.

---------------------------------------------------------------------
PART C — WATER + SPECIAL MATERIALS
---------------------------------------------------------------------
Your "river" is a flat blue slab. While you're in material-land, give
the water its own material: a translucent toon material with a slight
alpha and a horizontal contour-line texture (pen wavy lines), so it
reads as "drawn water" instead of a blue floor. Sketch:
  - MeshToonMaterial({ color: 0x1a365d, transparent: true, opacity: 0.85 })
  - add a subtle wavy line texture as map.

Don't over-invest here yet — Batch 7 redoes the river properly. Just
note it.
