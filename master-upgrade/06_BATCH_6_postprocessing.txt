=====================================================================
BATCH 6 — POST-PROCESSING: THE FINAL 10% THAT SELLS IT
=====================================================================
Time: ~2 hours. By now your map is outlined, hatched, toon-lit, and
fogged. This batch adds the finishing "print" feel: a subtle vignette,
a tiny color grade toward warm paper, the grain (if you skipped it),
and final sharpening. All of it lives in the EffectComposer you built
in Batch 3, as a chain of passes.

THE CHAIN (in this exact order):
  RenderPass -> OutlinePass -> ColorGradePass -> VignettePass -> GrainPass -> OutputPass

(If you skipped the composer in Batch 3, now is the time to add it —
post-processing is where the "gaming company" polish actually lives.)

---------------------------------------------------------------------
STEP 1 — COLOR GRADE (warm paper, slightly lifted blacks)
---------------------------------------------------------------------
Use three.js's built-in LUT or a tiny ShaderPass. Simplest: a ShaderPass
that warms the highlights and ever-so-slightly lifts the blacks (real
pen on paper never has pure #000).

  // grade.frag (GLSL)
  uniform sampler2D tDiffuse;
  varying vec2 vUv;
  void main(){
    vec3 c = texture2D(tDiffuse, vUv).rgb;
    // warm the highlights slightly
    c = mix(c, c * vec3(1.04, 1.01, 0.96), 0.5);
    // lift blacks a touch so nothing is pure black
    c = (c - 0.02) / 0.98;
    // slight desaturation for a matte paper feel
    float l = dot(c, vec3(0.299, 0.587, 0.114));
    c = mix(vec3(l), c, 0.92);
    gl_FragColor = vec4(c, 1.0);
  }

Values are starting points. Tune against your reference (if your ref is
high-contrast, don't lift blacks; if soft, lift more).

---------------------------------------------------------------------
STEP 2 — VIGNETTE (focus + "printed page" edge)
---------------------------------------------------------------------
A soft darkening at the corners draws the eye to the center and makes
the frame feel composed. Subtle.

  // vignette.frag (GLSL)
  uniform sampler2D tDiffuse; uniform float strength;
  varying vec2 vUv;
  void main(){
    vec3 c = texture2D(tDiffuse, vUv).rgb;
    vec2 d = vUv - 0.5;
    float r = length(d);
    float vig = smoothstep(0.7, 0.25, r);   // 1 center -> 0 edge
    c *= mix(1.0, vig, strength);           // strength ~0.35
    gl_FragColor = vec4(c, 1.0);
  }

---------------------------------------------------------------------
STEP 3 — GRAIN (if you didn't add it in Batch 4)
---------------------------------------------------------------------
Same as Batch 4 Part B. Last pass, amount ~0.02. Grain must be the
LAST thing before OutputPass so it sits on top of everything.

---------------------------------------------------------------------
STEP 4 — ORDER MATTERS
---------------------------------------------------------------------
Wrong order = broken look. Right order:
  outline (on geometry) -> color grade -> vignette -> grain -> output.

Do NOT put outline after grain, or the grain will get outlined.

---------------------------------------------------------------------
STEP 5 — PERFORMANCE GUARD
---------------------------------------------------------------------
Post-processing multiplies your render cost. Check your FPS now.
  - If < 30fps: reduce composer resolution (EffectComposer supports
    setPixelRatio / setSize), drop shadow mapSize to 1024, reduce
    outline edgeStrength, or disable vignette.
  - Keep grain and outline (they're cheap and high-impact). Cut
    vignette first if you must.

A "gaming-company" look means nothing at 15fps. Protect your framerate.

---------------------------------------------------------------------
DEFINITION OF DONE
---------------------------------------------------------------------
[ ] Post chain is Render->Outline->Grade->Vignette->Grain->Output.
[ ] Blacks are slightly lifted, highlights slightly warm (or matched
    to my reference).
[ ] Vignette subtle; grain subtle; outline intact.
[ ] FPS still smooth (>= 30, ideally 60).
[ ] Screenshot compared. The map now looks "finished," not "default".
