=====================================================================
BATCH 9 — LIFE & MOTION: MAKE THE WORLD BREATHE
=====================================================================
Time: ~3–4 hours. A beautiful but STATIC scene still reads "dead."
Gaming-company maps have constant subtle motion. This batch adds the
cheap, high-impact motion that makes your forest feel alive. It is all
cheap (no physics, just sine waves and lerps).

THE RULE OF SUBTLE:
  Motion should be NOTICED only when you look for it. If a tree is
  visibly flapping, it's wrong. Small amplitudes, slow speeds.

---------------------------------------------------------------------
1 — CANOPY SWAY (wind)
---------------------------------------------------------------------
Give canopies/tree tops a slow rotation around their base pivot:
  swayAngle = sin(time * 0.8 + phase) * 0.02   // ~1.1 degrees
  Apply to the canopy group's rotation.z (and a touch of x).

  - Phase per tree so they don't all move in sync.
  - Faster/none for giant trunks; more for leaves/grass.
  - Use a shared `clock.getElapsedTime()`.

---------------------------------------------------------------------
2 — GRASS & BAMBOO BEND
---------------------------------------------------------------------
Same idea, slightly larger amplitude, driven per-instance phase:
  grass.rotation.z = sin(t * 1.2 + phase) * 0.04;

For bamboo (many culms), stagger phases so waves pass through the
grove — one of the most "alive" feels you can get for free.

---------------------------------------------------------------------
3 — RIVER FLOW
---------------------------------------------------------------------
Scroll the water's contour-line texture (from Batch 4) slowly:
  waterTex.offset.y += 0.002 per frame;   // or offset.x for direction
Add a couple of floating "leaf/foam" dots drifting downstream on a
loop. Subtle, but it sells "water," not "blue slab."

---------------------------------------------------------------------
4 — THE LEAPING FISH (your signature asset — make it actually move)
---------------------------------------------------------------------
Your buildOrganicFish currently makes a static fish. It deserves a
loop: leap out of the water, arc, dive back. Cheap fake:

  - Keep the fish on a parametric arc over time:
      y(t) = sin(t * PI) * arcHeight
      x(t) = lerp(startX, endX, t)
  - Rotate it to face its velocity.
  - Add a tiny tail-wag (rotation.y oscillation) while airborne.
  - Loop t over 0..1 with a pause underwater between leaps.

This one asset, animated, becomes a moment players remember. Do it.

---------------------------------------------------------------------
5 — CAMPFIRE EMBERS
---------------------------------------------------------------------
Your concept mentions "crackling embers." Add a few tiny rising orange
dots with a slow upward drift + fade + small flicker in the fire's
light (if you gave it a light). Even 5 particles = alive hearth.

---------------------------------------------------------------------
6 — IDLE MICRO-MOTION ON PICKUPS & LANTERNS
---------------------------------------------------------------------
  - Pickups: gentle bob (y += sin(t*2 + phase) * 0.05) + slow spin.
  - Lanterns/grapple rings: tiny sway.
These are instant "polish" reads for almost no cost.

---------------------------------------------------------------------
7 — FOG DRIFT (optional, cheap atmosphere)
---------------------------------------------------------------------
If you want, slowly modulate fog density over a 20–30s cycle:
  scene.fog.density = base + sin(t * 0.05) * 0.001;
Very subtle. Gives the "mist in the woods" feel.

---------------------------------------------------------------------
IMPLEMENTATION NOTE
---------------------------------------------------------------------
Create ONE update(dt) function in your render loop that updates all
animated objects. Keep a list of {object, axis, speed, amplitude,
phase} and drive them in a single loop. Do NOT scatter setTimeouts or
per-object update code.

  const anim = [];
  function sway(obj, speed, amp, phase=0, axis='z') {
    anim.push({obj, speed, amp, phase, axis});
  }
  function update(dt) {
    const t = clock.getElapsedTime();
    for (const a of anim) a.obj.rotation[a.axis] =
      Math.sin(t * a.speed + a.phase) * a.amp;
    // ... plus river scroll, fish arc, embers ...
  }

DEFINITION OF DONE
---------------------------------------------------------------------

[ ] Water surface scrolls; river reads as flowing.
[ ] The leaping fish actually leaps on a loop.
[ ] Embers/pickups/lanterns have micro-motion.
[ ] All motion is subtle (you have to look to see it).
